# دفتر الفواتير والحسابات (Daftar Invoices & Ledger) 📒🧾

تطبيق أندرويد متكامل ومصمم بالكامل باللغة العربية ومن اليمين إلى اليسار (RTL)، مخصص لإدارة فواتير المبيعات وحسابات العملاء والملاحظات المسطرة، مع دعم الكتابة بين الأسطر ومحاكاة الدفاتر الورقية والطباعة الحرارية والمساعد الذكي.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. 📝 الكتابة بين الأسطر (Lined Paper Experience)
- محاكاة ورق الدفاتر التجارية مع خطوط مسطرة واضحة.
- الكتابة تتم في المساحات البيضاء النظيفة **بين الأسطر** وليس فوق الخط لضمان وضوح كامل للنصوص والأرقام.

### 2. 🧾 فواتير بيع أصناف (نقداً / آجل) - مطابقة للدفتر الورقي
- ترويسة تجارية رسمية مطابقة للدفاتر الورقية: اسم المحل، العنوان، التلفون، س.ت، ص.ب، فاكس، ورقم السند المميز باللون الأحمر (`0000337`).
- جدول الأصناف الرباعي:
  - **التفاصيل / Description**
  - **العدد / Qty**
  - **سعر الوحدة / Unit Price (ريال)**
  - **القيمة الإجمالية / Total Amount (ريال)** (حساب تلقائي فوري: الكمية × السعر).
- حساب المجموع الكلي (TOTAL) في أسفل الفاتورة.
- التحذير القانوني المطبوع: `* البضاعة المباعة لا ترد ولا تستبدل بعد خروجها من المحل ما عدا السهو والخطأ`.
- خانات التوقيع: توقيع المشتري وتوقيع البائع.

### 3. 👥 دفتر حسابات العملاء (Customer Ledger)
- جدول الحركات المحاسبية خماسي الأعمدة:
  1. **الرصيد التراكمي** (العمود الأول من اليمين - يُحسب تلقائياً مع كل حركة).
  2. **له / دائن** (المقبوضات باللون الأخضر).
  3. **عليه / مدين** (المستحقات باللون الأحمر).
  4. **التاريخ واليوم** (بشكل مصغر ومثقل).
  5. **التفاصيل / البيان** (بشكل مصغر وواضح).
- تجميع الحسابات في الأسفل: إجمالي له، إجمالي عليه، والرصيد الصافي المتبقي مع توضيح حالة الحساب (له أو عليه).

### 4. 🖨️ الطباعة الحرارية والمشاركة (Thermal Printing)
- معاينة حية للإيصال الحراري بمقاس 80mm / 58mm.
- طباعة مباشرة عبر مشغّل الطباعة في أندرويد (`Android PrintManager`).
- تصدير نصوص مهيأة للطابعات الحرارية (ESC/POS compatible).
- إمكانية مشاركة الفاتورة عبر واتساب والتطبيقات بضغطة زر.

### 5. 🤖 المساعد المحاسبي الذكي (Gemini AI)
- **محادثة ذكية متعددة الجولات (Multi-turn Chat):** مستشار محاسبي وتجاري متخصص مع دعم التبديل بين النماذج (`gemini-3.5-flash`, `gemini-3.1-pro-preview`, `gemini-3.1-flash-lite`).
- **توليد الأختام والشعارات:** توليد أختام تجارية رسمية باستخدام نموذج `gemini-3-pro-image-preview` مع إمكانية تحديد الدقة (`1K`, `2K`, `4K`).
- **القراءة الصوتية (TTS):** قراءة الفواتير والحسابات صوتياً باستخدام `gemini-3.8-flash-tts` ومحرك الصوت المدمج.

## 🛠️ البنية التقنية (Tech Stack)

- **لغة البرمجة:** Kotlin 2.x
- **واجهة المستخدم:** Jetpack Compose (Material Design 3)
- **النمط المعماري:** MVVM (Model-View-ViewModel) مع Clean Architecture
- **قاعدة البيانات المحلية:** Room Database 2.7.0 مع معالج الرموز KSP
- **الاتصال والذكاء الاصطناعي:** OkHttp / Retrofit مع Google Gemini API
- **الطباعة:** Android Print Framework + HTML Receipt Rendering
- **معالجة الصور:** Coil 2.7.0

## 🚀 كيفية البناء والتشغيل (Build & Run)

### المتطلبات الأساسية:
- JDK 17 أو أحدث.
- أندرويد استوديو (Android Studio Ladybug أو أحدث) أو بيئة Gradle.
- Android SDK 36 (minSdk 24).

### خطوات التشغيل:
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/USERNAME/REPO_NAME.git
   cd REPO_NAME
   ```
2. تهيئة ملف البيئة:
   ```bash
   cp .env.example .env
   ```
   *(أدخل مفتاح `GEMINI_API_KEY` في ملف `.env` للاستفادة من مزايا الذكاء الاصطناعي).*
3. بناء المشروع وتوليد نسخة الـ APK:
   ```bash
   ./gradlew assembleDebug
   ```
4. تشغيل الاختبارات:
   ```bash
   ./gradlew testDebugUnitTest
   ```

## 🔄 خط سير العمل المستمر (GitHub Actions CI)

يتضمن المشروع ملف أتمتة كامل في المسار `.github/workflows/android.yml` يقوم بالآتي عند كل عملية رفع (`push` أو `pull_request`):
- تهيئة بيئة Java 17 Temurin مع التخزين المؤقت لـ Gradle.
- تجهيز ملفات التكوين والبيئة تلقائياً.
- تنفيذ كافة اختبارات الوحدة الآلية (`testDebugUnitTest`).
- بناء ملف الـ APK النهائي (`assembleDebug`) ورفعه كـ Artifact جاهز للتنزيل المباشر.
